# Render Deployment Configuration for Phoenix_Nithya

This folder contains configuration files required to deploy the Phoenix_Nithya backend and frontend services on Render.

## Files
- `render.yaml`: Infrastructure-as-code file for Render multi-service deployment.
- `htil/backend/start.sh`: Startup script for backend service.
- `prediction/backend/start.sh`: Startup script for prediction backend service.

---

## render.yaml
This file defines the services to be deployed on Render.

## start.sh
Startup scripts for backend services to ensure proper environment setup and service launch.
